# AGENTS.md の形

そのまま埋める。**空になる節は落とす。** 埋めるために推測しない。

---

```markdown
# <repo 名>

**Generated:** <ISO8601 の日時>
**Commit:** <git rev-parse --short HEAD>

この印は「そのときのツリーを読んで書いた」を意味する。生成物は次のコミットに入るので、
**印が HEAD より古いのは正常**である。疑うかどうかは、**説明している対象が印より後に動いたか**で決める。

```sh
git log <印のコミット>..HEAD -- <この文書が説明している対象>
```

何も出なければ、印が古くても内容は正しい。出たら、その分だけ疑う。

## Repository

- Runtime: <言語 / ランタイム>
- Test: `<コマンド>`
- Lint: `<コマンド>`
- Build: `<コマンド>`

## How to navigate this codebase

- <ディレクトリ>: <そこが持つ責務を1行で>
- <ディレクトリ>: <同上>

## Conventions

- <この repo で守られている書き方。実際のコードで確かめたものだけ>

## Boundaries

- <触ってはいけないもの>: <なぜか>

## Dependencies

- Depends on: <外部サービス / 隣の repo>
- Depended on by: <あれば>

## Notes

- <引けない事実だけ。罠、経緯、機械が読めない制約>
```

---

## 各節の判定

| 節                  | 入れるもの                                     | 入れないもの                             |
| ------------------- | ---------------------------------------------- | ---------------------------------------- |
| Repository          | マニフェストから取ったコマンド                 | 動くはずのコマンド                       |
| How to navigate     | 実在するディレクトリと、その責務               | 将来置く予定の場所                       |
| Conventions         | コードで実際に守られている書き方               | 守らせたい理想                           |
| Boundaries          | 生成物、手で壊れるもの                         | 単に重要なファイル                       |
| Dependencies        | 設定と環境変数名に実在するもの                 | 使っているつもりのもの                   |
| Notes               | 🔴 **引けない事実だけ**                        | 行番号、キー名、テスト本数、実測値       |

## Notes に何を書くか

ここだけが「エージェントが自分で見つけられないもの」の置き場である。

**書く例**:

- この画面は旧経路が現役で、新経路からは到達しない
- この設定は本番と開発でずれており、両方で確認が要る
- この数字は仕様であって、直してはいけない

**書かない例**（環境から引けるので腐る）:

- テストは 126 本ある
- 該当は `foo.py` の 296 行目にある
- 応答のキーは `agent_name` である
