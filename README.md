# agent-workflow

エージェントと開発するための、マシンごとの道具立て。

Ghostty のタブで `claude` を立ち上げるだけで使える状態を目指す。herdr も pi も queue も要らない。

## 何を置くか

| 置き場                     | 中身                                             |
| -------------------------- | ------------------------------------------------ |
| `skills/`                  | 動詞ごとのスキル。`~/.claude/skills/` へ張る     |
| `hooks/`                   | ガードレール。`~/.claude/settings.json` から呼ぶ |

**プロジェクトの中には何も置かない。** 例外は各 repo の `AGENTS.md` 1枚だけで、それは生成物である。

## 3つの原則

**1. 文書は「引けない事実」だけを持つ。**
行番号・キー名・テスト本数・実測値は書かない。**引くコマンドを書く。**
1コマンドで引ける事実を文書に写すと、写した瞬間から腐りはじめる。

**2. 並列は「観点」で分ける。「誰か」では分けない。**
エージェントの種類で役割を決めると、同じ種類が2つ動いた瞬間に識別できなくなる。
観点（何を見るか）で分ければ、誰がやっても混ざらない。

**3. 短く保つ。**
長い文書は、1行1行が正しくても失敗する。注意が薄まるからである。
目安として、1ファイルは 10KB を超えない。

## 入れ方

```sh
./install.sh
```

`skills/` の各ディレクトリを `~/.claude/skills/` へ symlink する。冪等。
既に実体のディレクトリがある場合は上書きせず止まる。

## 使い方

Ghostty でタブを開き、対象の repo で `claude` を起動する。
スキルは名前で呼ぶ。

```
/agents-md          この repo の AGENTS.md を作り直す
```
