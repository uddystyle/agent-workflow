# 詰めて決める

🔴 **1問ずつ聞かない。** いま答えられる問いを**全部まとめて**出す。
1問ずつ聞くと、往復の数だけ時間が延び、**人は同じ文脈を何度も思い出すことになる**。

## 1. 決定を木にする

案を、**決定とその下にぶら下がる決定**として並べる。

「どこに置くか」が決まらないと「どう配るか」は決められない。**前提が先、依存が後**である。

**完了条件**: 決定を3つ以上挙げ、どれがどれの前提かを言える。

## 2. いま答えられるものを全部出す

**frontier** ＝ 前提が既に決まっていて、**推測なしに答えられる**問い。それを1回でまとめて出す。

- **番号を振る**
- 🔴 **それぞれに推奨を添える。** 「どうしますか」だけでは、考える仕事を丸投げしている
- ⚠️ **まだ前提が決まっていない問いは出さない。** 答えても、前提が変われば無効になる

**完了条件**: 出した問いすべてについて、**いま答えられる理由**を言える。

## 3. 答えを受けて、木を組み替える

決まった決定は前提になり、**その先の問いが答えられるようになる**。frontier は外へ広がる。

⚠️ **答えを聞いたら、前提が変わっていないかを見る。** 前の答えを無効にする答えが来たら、
そこから先を作り直す——**黙って古い前提のまま進めない**。

**完了条件**: 前ラウンドの答えが、次に出す問いの前提として使われている。

## 4. frontier が空になったら終わる

🔴 **終わりは「質問が尽きた」ではなく「黙って仮定したものが無い」である。**

答えを聞かずに埋めた箇所が1つでもあれば、それは**問いを飛ばした**ということ。戻って出す。

**完了条件**: 木のどの枝も訪れており、**答えのない仮定が残っていない**。

## 5. 合意を確かめてから動く

🔴 **人が「これで合っている」と言うまで、実装に入らない。**

⚠️ **要約を返して合意を取る。** 長い対話の後は、**何が決まったか**を短く並べ直す——
決めた本人も、全部は覚えていない。

**完了条件**: 決まったことの一覧を出し、人がそれを認めた。
