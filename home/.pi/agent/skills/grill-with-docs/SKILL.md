# 詰めて、残す

**この skill は繋ぐだけである。** 中身は2本が持つ。

1. **`grilling`** —— 答えられる問いをまとめて出し、frontier が空になるまで詰める
2. **`domain-modeling`** —— 出てきた言葉を揃え、判断のうち**残すべきものだけ**を書く

🔴 **順に呼ぶ。** 詰める前に書くと、**変わる前提を文書にすることになる**。

## 残すもの・残さないもの

`grilling` の1ラウンドごとに決定が積まれる。⚠️ **全部は残さない。**

- **言葉**（同じものを2通りに呼んでいた、語の指す範囲が割れた）→ `CONTEXT.md`
- **判断** → 3条件を**全部**満たすものだけ（`domain-modeling` §4）

🔴 **1件1ファイルに割らない。** 判断は既にある置き場へ積む。新しく作る前に探す。

## 完了条件

frontier が空になり、決まったことの一覧を人が認めている（`grilling` §5）。
そのうえで、**残した言葉と判断のそれぞれについて、置いた場所を言える**。

⚠️ **残さなかったものも言える。** 「3条件を満たさないので書かなかった」が言えないなら、
判断を落としたのか、そもそも出なかったのかが区別できない。
